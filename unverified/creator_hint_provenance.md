# Provenance pass: what the creator actually instructed, by scope

Extracted from the 445-message authenticated transcript: every creator statement touching
prime / zero / yellow / blue / matrixsumlist / dbbi / faed / "in front of your eyes" /
"very last step" / yin-yang, with the message each replied to, in chronological order.

**Result: only 10 of 510 rows are creator-authenticated (HINT or CONFIRM) on these topics in
seven years — and they are not all about the same object.** The community (and earlier work
in this repo) has been merging three differently-scoped threads.

## The 2020-05 cluster is one conversation, and it has been overlooked

```
#4096  2020-05-20  META     re-points to the poem as THE official hint
                            ("Yellow has a number and so does Blue. Go back to the first
                             puzzle piece...")
#4102  2020-05-21  CONFIRM  "answer is there"
#4105  2020-05-21  HINT     "First or zero"          <- tagged P0 HINT2020
```

`#4105` is a creator **HINT** that has not been factored into any construction here. Two
readings, both live, and the distinction matters:

**(a) It answers the poem's riddle.** "Yellow has a number and so does Blue" → the numbers
are **first or zero**, i.e. **1 and 0**. Under this reading the colours contribute only bit
values, which is exactly what the Phase-0 decode already uses (blue=1, yellow=0), and the
counts reading (yellow=9, blue=15) is **wrong**. This is consistent with
`phase0_yellow_blue_counts.md`, which independently found the colouring merely restates the
URL's own LSBs and so carries no separate value.

**(b) It disambiguates which image.** "First [puzzle piece]" = "[phase] zero" — i.e. the
poem's "first puzzle piece" means the genesis image. This is the archive annotator's reading.

Under **either** reading, `yellowblueprimes` is not licensed to mean "9, 15, and primes".
Under (a) it is positively excluded.

## What this closes and what it opens

- The 9/15 counts have no creator warrant. Every construction in this repo that fed `9`,
  `15`, `915` or `159` as operands was using a community inference, not an instruction.
- `yellowblueprimes` as a single atomic operator is unsupported. The token appears once,
  inside a 2023 list that also contains already-solved stage names
  (`matrixsumlist`, `lastwordsbeforearchichoice`), followed immediately by
  `wewontgiveawaythepassword` / `itsinfrontofyoureyesbutyourenotseeingit`. That list reads
  more like a **table of contents of the stages** than a recipe, with the password stated to
  be something else already visible.
- The prime instruction is scoped to **SalPhaseIon**, and its only concrete anchor remains
  the 2021-03-01 exchange about **2, 3, 5, 7** plus the 2021-12-26 "some characters need to
  be zeroed out".

## Method note

This is the pass that should precede any further transform work: build from instructions
with provenance and reply-context, not from numerical coincidences. Of the seven years of
chatter, the actionable creator instruction set on these topics is ten statements, and two
of them (#4102, #4105) had never been used.
